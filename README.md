# ゼビウスエディッタ PS1版（ナムコミュージアムVol.2）

レトロゲームファンオリジナルゼビウスエディッタの PS1版です。
PS1『ナムコミュージアムVol.2』のゼビウスを、ブラウザだけで改造できます。

- **Web版**: https://koudaken77777-ship-it.github.io/xevious-ps1-editor/
- **ダウンロード版**: [Releases](https://github.com/koudaken77777-ship-it/xevious-ps1-editor/releases/latest) の html ファイルをダブルクリック

## できること
- 地形・地上敵・空中敵・バキュラ・ドモグラム・メッセージ・地上絵の編集
- 壊せるバキュラ（弾数・得点・数字表示・SPECIAL BONUS メッセージ）
- 自機の絵の変更、エリア数の追加（最大18）
- ブラウザの中でテストプレイ（内蔵の互換BIOS「OpenBIOS」で動きます）
- 改造ディスク（.bin/.cue）の書き出し

## 使い方
1. エディッタを開いて、お持ちの『ナムコミュージアムVol.2』の Track 01 の .bin（と .cue）を読み込みます。
2. 編集してテストプレイで確かめ、「ディスクの保存」で改造ディスクを書き出します。

ゲームのディスクイメージや BIOS はこのリポジトリには含まれていません。ご自身でお持ちのものをお使いください。

## 不具合報告
エディッタ右上の「🐞 不具合を報告」から送れます（エディッタの版・ブラウザ・直前のエラーが自動で入ります）。
